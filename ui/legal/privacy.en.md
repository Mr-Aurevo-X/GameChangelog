## 1. Publisher collection: none

Mr-Aurevo-X does not collect personal data on its servers. No analytics tracker, no crash telemetry, no user account. The watchlist is not sent to Mr-Aurevo-X.

## 2. Local

Watchlist, changelog cache, bugs and app settings: `%LOCALAPPDATA%\ChangeLog-Central\`.

Shared preferences (language, accent, update check): `%LOCALAPPDATA%\Mr-Aurevo-X\user-settings.json` — a file shared with other Mr-Aurevo-X apps. Do not delete it if other programs still use it.

## 3. Network (usage-initiated)

- Steam APIs (search, news, events, status)
- `api.github.com` (version notice, read-only, if enabled in About)
- Browser: Steam / SteamDB / releases pages (user click)
- Discord / PayPal / Revolut buttons: those operators’ sites — a click leaves the app

No in-app download or install from GitHub.
